## What does this mod do?
This mods purpose is to generate LODs for the mod [Voxy](https://modrinth.com/mod/voxy) but without actually saving the Chunks generated, like other Voxy addons do. Similar to what Distance Horizons does. This saves a lot of storage space and also allows you to generate new chunks without traveling thousands of blocks after a Minecraft update.
